# BetScope — анализ ставок у российских букмекеров

Русскоязычное приложение для сравнения коэффициентов **российских легальных букмекеров**,
поиска вилок и ставок с перевесом, моделирования матчей и учёта банкролла.

Никаких ключей API и регистрации не нужно: линии берутся напрямую из публичных фидов
самих контор. Демо- и мок-данных в проекте нет — только живые котировки.

## Источники

| Контора | Что берём |
|---|---|
| **Фонбет** | полный фид линии `currentLine` (все виды спорта, прематч и лайв) |
| **Лига Ставок** | публичное API витрины по видам спорта |
| **Winline** | публичное API витрины по видам спорта |
| **Олимп** | публичное API линии |

Все четыре работают по лицензии ФНС РФ через ЕЦУПС. Ставки вы делаете на их сайтах —
BetScope только анализирует и подсказывает, где цена лучше.

## Запуск

```bash
npm install
npm run dev     # http://localhost:3000
```

> **Важно:** запускать нужно там, где есть прямой доступ к сайтам букмекеров — то есть
> на российском интернете без VPN. С зарубежного сервера или из изолированной песочницы
> конторы не ответят, и приложение честно покажет это в статусе источников.
> В облачной среде, где доступен только GitHub, данных не будет — это ограничение сети,
> а не приложения.

Статус каждой конторы (сколько событий отдала, за сколько мс, какая ошибка) виден на каждой
странице и в разделе «Настройки → Проверить доступность контор».

## Разделы

| Раздел | Что делает |
|---|---|
| **Обзор** | Сводка: сколько матчей в линии, сколько сравнимо между конторами, топ вилок и value, ROI ваших ставок |
| **Сравнение линий** | Все рынки матча: исход, двойной шанс, тоталы по каждой линии, форы, обе забьют. Лучшая цена подсвечена зелёным, рядом — котировки всех контор и маржа |
| **Вилки** | Поиск арбитража между конторами, раскладка ставок под ваш банк с округлением и гарантированной прибылью, ссылки на события |
| **Value-ставки** | Справедливая цена как консенсус российских контор, перевес, EV, Kelly, рекомендуемая сумма, отправка в трекер |
| **Модели** | Пуассон с автокалибровкой ожидаемых голов по рыночному тоталу и линии исхода; сравнение модели с ценами контор |
| **Калькуляторы** | Kelly/EV, вилка и дачинг, хедж, экспресс, конвертер, маржа и CLV, **НДФЛ 13%** (с одной ставки и за год по выводам) |
| **Мои ставки** | Учёт ставок, ROI, проходимость, кривая прибыли, разбивка по конторам/рынкам/видам спорта, экспорт CSV |
| **Настройки** | Проверка доступности контор, виды спорта, пороги сканера, банкролл, доля Kelly |

## Как устроено сопоставление матчей

Разные конторы пишут команды по-разному: «ФК Зенит», «Зенит», «Зенит (СПб)». Приложение
нормализует названия (убирает префиксы ФК/ХК, скобки, приводит ё→е), считает токенную
схожесть и объединяет события с порогом 0.72 в окне ±3 часа. Если контора поменяла хозяев
и гостей местами, котировки автоматически переворачиваются вместе с форами.

## Математика

- **Снятие маржи** — модель **Shin** (решение бинарным поиском) или пропорциональная нормализация.
- **Вилка** — `Σ 1/oᵢ < 1` по лучшим ценам разных контор; ставки распределяются пропорционально `1/oᵢ`.
- **Value** — у каждой конторы снимается маржа, вероятности усредняются в консенсус; перевес = лучшая цена / справедливая − 1.
- **Kelly** — `f = (b·p − q)/b` с настраиваемой долей (по умолчанию 1/4).
- **Пуассон** — матрица счетов 11×11 → 1X2, тоталы, обе забьют, точный счёт.
- **CLV** — сравнение взятой цены с закрывающей.

Ядро изолировано в `src/lib/math.ts` и `src/lib/books/analyze.ts`, от UI не зависит.

## Добавить свою контору

Создайте файл в `src/lib/books/`, реализуйте `BookAdapter` (вернуть `BookEvent[]` в единой
модели) и добавьте его в массив `ADAPTERS` в `src/lib/books/index.ts`. Остальное — слияние,
вилки, value, интерфейс — заработает автоматически.

## Дисклеймер

Инструмент аналитический: не принимает ставки, не является букмекером и не гарантирует прибыль.
Коэффициенты меняются в реальном времени, за систематический арбитраж конторы режут максимумы
и закрывают счета. С выигрышей удерживается НДФЛ 13%. Ставьте только те суммы, потеря которых
для вас приемлема.
