# Ставка PRO — анализ линий российских букмекеров

Русскоязычное приложение для сравнения коэффициентов **российских легальных букмекеров**,
поиска вилок и ставок с перевесом, моделирования матчей и учёта банкролла.

Никаких ключей API и регистрации не нужно: линии берутся напрямую из публичных фидов
самих контор. Демо- и мок-данных в проекте нет — только живые котировки.

## Источники

Линии читаются напрямую из **официальных публичных фидов** — тех же данных,
которыми пользуются сайты самих контор. Ни ключей API, ни регистрации, ни
сторонних агрегаторов.

| Контора | Что берём |
|---|---|
| **Фонбет** | полный фид линии `currentLine` + платформа `bk6bba-resources.com` (прематч и лайв, все виды спорта) |
| **Лига Ставок** | официальное REST-API витрины `lds-api-sites.ligastavok.ru` |
| **Леон** | официальное REST-API `leon.ru/api-2` (прематч и лайв) |
| **Олимп** | официальное REST-API `olimp.bet/api/v4` (прематч и лайв) |
| **Марафон** | фид платформы линии `tf39be-resources.com` |
| **ПАРИ** | фид платформы линии `pb06e2-resources.com` |
| **Беттери** | фид платформы линии `at58f5-resources.com` |
| **Зенит** | AJAX-фид линии `zenit.win` |

Фонбет, Марафон, ПАРИ и Беттери работают на единой платформе линии: один JSON
содержит всю линию целиком — и ближайшие матчи, и события на несколько недель
вперёд (прематч), плюс отдельный лайв-фид.

**Почему не Winline и БетБум:** их сайты не имеют публичных фидов линии и
защищены от автоматических запросов — серверное чтение их котировок без
браузера невозможно. Вместо них в сканере работают Леон и Беттери.

Все конторы работают по лицензии ФНС РФ через ЕЦУПС. Ставки вы делаете на их сайтах —
BetScope только анализирует и подсказывает, где цена лучше.

## Запуск на Windows — в один клик

Дважды щёлкните **`Запустить.bat`** — больше ничего делать не нужно.
Скрипт сам находит Node.js (при отсутствии ставит через winget в тихом режиме
и подхватывает без перезапуска окна), устанавливает зависимости, собирает
приложение, выбирает свободный порт и открывает браузер.

В первые 10 секунд после запуска можно выбрать режим (если ничего не нажимать,
включится обычный):

| Клавиша | Режим | Что делает |
|---|---|---|
| `1` | Обычный (по умолчанию) | `npm install` → `npm run build` → `npx next start` |
| `2` | Разработка | `npm install && npm run dev` — hot-reload, полные ошибки в консоли, первый запуск без сборки |

Режим разработки удобен, когда нужно понять, почему конторы не отвечают:
в консоль выводятся полные тексты ошибок обращений к фидам букмекеров.

Сервер слушает только `127.0.0.1`, поэтому Windows **не показывает запрос
брандмауэра**. Ожидание готовности сделано на PowerShell — внешние утилиты
вроде `curl` не нужны. Если порт 3000 занят, берётся следующий свободный.

Первый запуск — 4–7 минут, последующие — секунды.
Если что-то сломалось: **`Переустановить.bat`**.
Краткая инструкция для пользователя — в файле `ПРОЧТИ МЕНЯ.txt`.

## Если конторы не отвечают

Запустите **`Диагностика.bat`** (лежит рядом с `Запустить.bat`). Он за минуту проверяет
каждый адрес фида по цепочке DNS → TCP → TLS → HTTP, отдельно проверяет, проходит ли
соединение без проверки сертификата (так ловится перехват HTTPS антивирусом), и сохраняет
отчёт `diag-report.txt` с вердиктом.

Типичные причины, которые она выявляет:

| В отчёте | Причина | Что делать |
|---|---|---|
| `Сертификат не принят` + «без проверки сертификата проходит» | антивирус/прокси подменяет сертификат | отключить проверку защищённых соединений в антивирусе или выставить `NODE_EXTRA_CA_CERTS` |
| `DNS: адрес не найден` | имя не отдал ни системный DNS, ни резервные, ни DNS-over-HTTPS | адрес блокируется в самой сети — попробуйте другую сеть или мобильный интернет |
| `Соединение сброшено`, `таймаут` | провайдер или корпоративный прокси режет адреса | попробовать другой интернет / отключить прокси |
| `HTTP 403`, `Ответ не JSON` | контора включила защиту от ботов | правится в коде адаптера по отчёту |

В разделе **Настройки → Проверить доступность контор** показывается не только ошибка, но и
какие адреса проверялись, чем закончился каждый и как был найден адрес рабочего зеркала.

## Адреса контор и резервный DNS

Адреса берутся своим резолвером (`src/lib/books/net.ts`), а не системным `fetch`:

1. **Системный DNS** — быстро и привычно, как у браузера.
2. Если он не находит имя — **публичные DNS по UDP**: `8.8.8.8`, `1.1.1.1`, `77.88.8.8`, `9.9.9.9`
   (все параллельно, кто первый ответит).
3. Если и они молчат — **DNS-over-HTTPS**: Яндекс, AdGuard, Google, Cloudflare. Запрос уходит
   на жёстко прописанный IP сервиса, поэтому DNS для него не нужен вовсе.

Соединение всегда идёт по найденному IP, но с правильным SNI и `Host`, так что сайты контор
видят обычный запрос. Когда адрес найден не системным DNS, интерфейс прямо об этом пишет
(«адрес найден через резервный DNS: …»). Резервные серверы спрашивают только имена сайтов
контор — больше ничего наружу не уходит.

Отключить:

* в интерфейсе — **Настройки → Поиск адресов контор (DNS) → только системный DNS**;
* переменной окружения `BOOKS_DNS_FALLBACK=0` (то же самое для `node diag.mjs` действует
  всегда включённым).

Зеркала одной конторы проверяются **параллельно**: берётся первый адрес, ответивший валидной
линией, остальные запросы отменяются, а рабочий адрес запоминается на 10 минут. Поэтому
«мёртвое» зеркало в списке больше не даёт ложную ошибку «DNS: адрес не найден», если живое
зеркало ответило.

## Запуск вручную (любая ОС)

```bash
npm install
npm run build
npm run start   # http://localhost:3000
```

> **Важно:** линии приходят напрямую с сайтов контор, поэтому запускать приложение нужно
> там, где эти сайты доступны. С зарубежного сервера или из изолированной песочницы конторы
> не ответят, и приложение честно покажет это в статусе источников.
> В облачной среде, где доступен только GitHub, данных не будет — это ограничение сети,
> а не приложения.

Статус каждой конторы (сколько событий отдала, за сколько мс, какая ошибка) виден на каждой
странице и в разделе «Настройки → Проверить доступность контор».

## Разделы

| Раздел | Что делает |
|---|---|
| **Обзор** | Сводка: сколько матчей в линии, сколько сравнимо между конторами, топ вилок и value, ROI ваших ставок |
| **Сравнение линий** | Все рынки матча: исход, тоталы по каждой линии, форы, где есть — двойной шанс и обе забьют. Лучшая цена подсвечена зелёным, рядом — котировки всех контор и маржа. Фильтр периода: сегодня / 3 дня / неделя / месяц / вся линия — видны и будущие события, а не только текущие. Кнопка «показать ещё» подгружает список по 100 матчей |
| **Вилки** | Поиск арбитража между конторами, раскладка ставок под ваш банк с округлением и гарантированной прибылью, ссылки на события |
| **Value-ставки** | Справедливая цена как консенсус российских контор, перевес, EV, Kelly, рекомендуемая сумма, отправка в трекер |
| **Модели** | Пуассон с автокалибровкой ожидаемых голов по рыночному тоталу и линии исхода; сравнение модели с ценами контор |
| **Калькуляторы** | Kelly/EV, вилка и дачинг, хедж, экспресс, конвертер, маржа и CLV, **НДФЛ 13%** (с одной ставки и за год по выводам) |
| **Мои ставки** | Учёт ставок, ROI, проходимость, кривая прибыли, разбивка по конторам/рынкам/видам спорта, экспорт CSV |
| **Настройки** | Проверка доступности контор, виды спорта, пороги сканера, банкролл, доля Kelly |

## Как устроено сопоставление матчей

Разные конторы пишут команды по-разному: «ФК Зенит», «Зенит», «Зенит (СПб)». Приложение
нормализует названия (убирает префиксы ФК/ХК, скобки, приводит ё→е), считает токенную
схожесть и объединяет события с порогом 0.72 в окне ±3 часа. Если контора поменяла хозяев
и гостей местами, котировки автоматически переворачиваются вместе с форами.

## Математика

- **Снятие маржи** — модель **Shin** (решение бинарным поиском) или пропорциональная нормализация.
- **Вилка** — `Σ 1/oᵢ < 1` по лучшим ценам разных контор; ставки распределяются пропорционально `1/oᵢ`.
- **Value** — у каждой конторы снимается маржа, вероятности усредняются в консенсус; перевес = лучшая цена / справедливая − 1.
- **Kelly** — `f = (b·p − q)/b` с настраиваемой долей (по умолчанию 1/4).
- **Пуассон** — матрица счетов 11×11 → 1X2, тоталы, обе забьют, точный счёт.
- **CLV** — сравнение взятой цены с закрывающей.

Ядро изолировано в `src/lib/math.ts` и `src/lib/books/analyze.ts`, от UI не зависит.

## Виды спорта и будущие события

Доступны все виды спорта сразу — футбол, хоккей, теннис, баскетбол, волейбол, настольный
теннис, ММА/бокс и киберспорт. Ограничения «до 4 видов» больше нет: в «Вилках», «Value»
и «Настройках» можно включить все восемь, сканер опросит каждый.

В «Сравнении линий» есть фильтр периода (сегодня / 3 дня / неделя / месяц / вся линия):
прематч-фиды отдают события на недели вперёд, поэтому список не ограничен текущими
матчами. Один и тот же фид конторы кэшируется на 20 секунд — скан по нескольким видам
спорта не качает его повторно.

## Проверка парсеров без интернета

```bash
npm run test:parsers
```

Компилирует адаптеры и прогоняет 40+ проверок на фикстурах — схемы ответов всех
официальных фидов (платформа линии, Лига Ставок, Олимп, Зенит, Леон) и сквозное
слияние матчей двух контор. Тесты не ходят в сеть и работают даже там, где конторы
недоступны.

## Добавить свою контору

Создайте файл в `src/lib/books/`, реализуйте `BookAdapter` (вернуть `BookEvent[]` в единой
модели) и добавьте его в массив `ADAPTERS` в `src/lib/books/index.ts`. Остальное — слияние,
вилки, value, интерфейс — заработает автоматически.

## Дисклеймер

Инструмент аналитический: не принимает ставки, не является букмекером и не гарантирует прибыль.
Коэффициенты меняются в реальном времени, за систематический арбитраж конторы режут максимумы
и закрывают счета. С выигрышей удерживается НДФЛ 13%. Ставьте только те суммы, потеря которых
для вас приемлема.
