# BetScope — аналитика ставок на спорт

Веб-приложение для анализа коэффициентов букмекеров на разных платформах: сравнение линий,
поиск арбитражных ситуаций (вилок) и ставок с положительным ожиданием (value), математические
модели матчей, калькуляторы и учёт собственного банкролла.

Работает **только на актуальных данных** [The Odds API](https://the-odds-api.com/) — демо- и
мок-данных в проекте нет. Без ключа интерфейс явно сообщает, что источник не подключён.

## Быстрый старт

```bash
npm install
cp .env.example .env.local   # впишите свой ODDS_API_KEY
npm run dev                  # http://localhost:3000
```

Ключ получается бесплатно на the-odds-api.com (500 запросов в месяц на free-тарифе).

```env
ODDS_API_KEY=ваш_ключ
ODDS_API_REGIONS=eu,uk,us   # регионы букмекеров: eu, uk, us, au
```

Ключ читается только на сервере и никогда не попадает в браузер.

## Возможности

| Раздел | Что делает |
|---|---|
| **Обзор** | Сводка по выбранным лигам: сколько событий просканировано, топ вилок и value-ставок, ROI вашего банкролла |
| **Сравнение линий** | Лучшая цена по каждому исходу среди всех букмекеров, полный список котировок, маржа каждой конторы, форматы коэффициентов (десятичные, американские, дробные, вероятности) |
| **Вилки** | Сканирование нескольких лиг и рынков сразу, расчёт распределения ставок под заданный банк с округлением и гарантированной прибылью |
| **Value-ставки** | Справедливая вероятность считается по консенсусу рынка со снятием маржи, сравнивается с лучшей ценой; EV, Kelly, рекомендуемая сумма, отправка в трекер одним кликом |
| **Модели** | Модель Пуассона с автокалибровкой λ по рыночному тоталу и линии 1X2: вероятности 1X2, тоталов, обе забьют, точных счетов и сравнение с рынком |
| **Калькуляторы** | Kelly/EV, вилка и дач-беттинг, хеджирование, экспресс, конвертер коэффициентов, маржа букмекера и CLV |
| **Мои ставки** | Учёт ставок, ROI, проходимость, кривая прибыли, разбивка по букмекерам/рынкам/видам спорта, экспорт CSV |
| **Результаты** | Живые и завершённые матчи со счётом, автообновление каждую минуту |
| **Настройки** | Статус API и остаток квоты, лиги, рынки, регионы, пороги сканера, банкролл, доля Kelly |

## Математика

- **Снятие маржи** — два метода: пропорциональная нормализация и модель **Shin**, которая
  учитывает долю инсайдерской торговли и точнее описывает favourite–longshot bias.
  Решение уравнения Шина — бинарным поиском по z.
- **Арбитраж** — сумма обратных коэффициентов лучших цен `Σ 1/oᵢ < 1`; ставки распределяются
  пропорционально `1/oᵢ`, что даёт одинаковую прибыль при любом исходе.
- **Value** — по каждому букмекеру снимается маржа, вероятности усредняются в консенсус;
  перевес = `лучшая цена / справедливая цена − 1`.
- **Kelly** — `f = (b·p − q)/b` с настраиваемой дробной долей (по умолчанию 1/4).
- **Пуассон** — матрица вероятностей счетов 11×11, из неё выводятся 1X2, тоталы, BTTS.
- **CLV** — сравнение взятой цены с закрывающей, главный индикатор долгосрочного преимущества.

Ядро расчётов изолировано в `src/lib/math.ts` и не зависит от UI.

## Структура

```
src/
  app/
    api/            маршруты к The Odds API (ключ только на сервере)
      sports  odds  arbs  value  scores  event  status
    odds/ arbitrage/ value/ models/ calculators/ tracker/ scores/ settings/
  components/       Shell (навигация + статус API), контролы, UI-примитивы
  lib/
    odds-api.ts     клиент The Odds API, разбор квоты из заголовков, кеширование
    math.ts         вся математика ставок
    types.ts        доменные типы
    prefs.ts        настройки пользователя (localStorage)
```

Стек: Next.js 14 (App Router), TypeScript, Tailwind CSS, Recharts.

## Расход квоты

Стоимость запроса = `число регионов × число рынков`. Сканирование 6 лиг по 3 рынкам в 2 регионах
стоит 36 запросов. Следите за остатком в сайдбаре, держите автообновление выключенным при
экономии квоты и не выбирайте лишние регионы.

## Дисклеймер

Инструмент аналитический: он не принимает ставки и не гарантирует прибыль. Коэффициенты меняются
в реальном времени, букмекеры ограничивают счета за арбитраж. Ставьте только те суммы, потеря
которых для вас приемлема.
